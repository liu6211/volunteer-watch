# QQ 邮箱中转服务

「志愿项目监控」App 用它来把通知发到你的 QQ 邮箱。

**为什么要这个东西**：手机 App 的运行环境没有原始 socket，连不上 QQ 的
SMTP 服务器（`smtp.qq.com:465`）。现有能直连的第三方库都已停止维护，
硬加会破坏 App 的构建。所以让这个 30 行的小服务代发。

---

## 一、先拿到 QQ 邮箱授权码

1. 电脑浏览器打开 QQ 邮箱网页版并登录
2. 顶部 → **设置** → **账号**
3. 找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」
4. 开启 **IMAP/SMTP服务**（需要手机发短信验证）
5. 验证后会弹出 **16 位授权码**，复制保存

> ⚠️ 授权码 ≠ QQ 登录密码。填密码一定失败。

---

## 二、启动服务

需要电脑上装了 Node.js（建议 18 以上）。

```bash
cd tools/qq-mail-relay
npm install
```

然后设置环境变量并启动。

### Windows PowerShell

```powershell
$env:QQ_USER      = "180957824@qq.com"
$env:QQ_AUTH_CODE = "你复制到的16位授权码"
node server.js
```

### macOS / Linux

```bash
QQ_USER="180957824@qq.com" \
QQ_AUTH_CODE="你复制到的16位授权码" \
node server.js
```

启动成功会看到：

```
✅ QQ 邮箱 SMTP 登录成功，可以发信了

========================================
  QQ 邮箱中转服务已启动
========================================
  监听端口 : 3000
  发件邮箱 : 180957824@qq.com
  鉴权     : 未开启（可选）

  App 里要填的地址（按你用哪台机器访问选一个）：
    http://192.168.0.238:3000/
```

**把最后那个地址记下来**，等下要填进 App。

---

## 三、填进 App

App → **设置** → **邮箱通知**：

| 项目 | 填什么 |
|---|---|
| 发现新项目时发邮件 | 打开 |
| 收件邮箱 | 你想收通知的邮箱（可以就是同一个 QQ 邮箱） |
| 发送通道 | 选 **自建中转** |
| 中转接口地址 | 上面那个 `http://192.168.x.x:3000/` |

然后点 **「发送测试邮件」** → 显示 ✅ 就说明通了。

---

## 四、可选的环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `3000` | 监听端口 |
| `QQ_USER` | 必填 | 发件用的 QQ 邮箱 |
| `QQ_AUTH_CODE` | 必填 | 16 位授权码 |
| `QQ_FROM` | 同 `QQ_USER` | 发件人显示地址 |
| `RELAY_TOKEN` | 空 | 设了之后请求必须带 `x-relay-token` 头，防止被别人当免费发信机 |

## 五、接口说明

```
GET  /health
     → {"ok":true,"service":"qq-mail-relay","from":"..."}

POST /
     Content-Type: application/json
     {"to":"a@b.com","subject":"标题","text":"正文","from":"可选"}

     成功 → 200 {"ok":true,"messageId":"..."}
     失败 → 4xx/5xx {"ok":false,"error":"原因"}
```

## 六、常见问题

**启动就报「QQ 邮箱登录失败」**
- 授权码填错了（最常见）。注意不是 QQ 密码。
- 没在 QQ 邮箱里开启 IMAP/SMTP 服务。
- 授权码重新生成过，旧的失效了。

**App 里测试报「请求超时」**
- 手机和这台电脑不在同一网络。
- 电脑防火墙拦了 3000 端口（Windows 会弹窗问，要选「允许」）。
- 地址写错了（注意结尾的斜杠可有可无，但 IP 要写对）。

**想在外面（不在家）也能收到邮件**
- 需要有公网地址。最省事的做法是换个方案：用 App 里内置的
  **Brevo** 通道，它不需要你自己有服务器。

**服务关掉后还会发邮件吗**
- 不会。这个中转必须一直开着。所以更推荐 Brevo 方案。
